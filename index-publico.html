Seguridad Institucional

Protección de datos de nivel institucional

Contraseñas con bcrypt

Nunca se guardan en texto plano. Hash irreversible de grado industrial.

Row Level Security

RLS activo en todas las tablas. Sin permisos, no hay acceso a datos.

PDFs con URL firmada

Los documentos expiran en 1 hora. Nadie sin autorización puede verlos.

Auditoría con IP

Cada acción queda registrada con usuario, fecha y dirección IP.

Arquitectura Moderna

Infraestructura serverless

Frontend

Backend

Reportes
